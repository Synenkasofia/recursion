Практична робота: Рекурсія

Усі завдання реалізовані рекурсивно без використання циклів.

## Завдання

1. Виведення рядка у зворотному порядку.
2. Перестановка кожних двох сусідніх вузлів зв'язаного списку.
3. Обчислення числа Фібоначчі.
4. Обчислення кількості способів піднятися сходами.
5. Рекурсивне піднесення числа до степеня.
